---
description: Erklärt eine Datei oder Methode Zeile für Zeile mit Beispielwerten und stellt danach Verständnisfragen
argument-hint: [datei oder methode]
disable-model-invocation: true
---

Erkläre $ARGUMENTS so, dass Mani jede Zeile selbst erklären kann.

1. Ein Satz: Wozu gibt es diesen Code?
2. Zeile für Zeile (oder in kleinen Blöcken): was passiert, mit einem konkreten Beispielwert, der durch den Code läuft.
3. Warum so? Nenne eine naheliegende Alternative und warum sie hier schlechter wäre.
4. Welche Tests sichern diesen Code ab? Welcher Fall ist noch nicht getestet?
5. Stelle am Ende zwei Verständnisfragen. Gib die Antworten NICHT. Warte auf Manis Antwort und gib dann kurzes, ehrliches Feedback.

Ändere dabei keine Dateien.
